## 🚀 Getting Started

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/Charanteja5735/ai-portfolio.git

# 2. Open the file directly in your browser
# Just double-click index.html — no server needed!
```

### Setup API Keys

**For AI Chatbot (OpenAI):**
1. Go to [platform.openai.com](https://platform.openai.com)
2. Create an API key
3. Open `index.html` → find this line:
```javascript
const OPENAI_API_KEY = "your-key-here";
```
4. Replace with your actual key

**For Contact Form (Web3Forms):**
1. Go to [web3forms.com](https://web3forms.com)
2. Enter your email and get a free access key
3. Open `index.html` → find this line:
```html
<input type="hidden" name="access_key" value="WEB3FORMS_KEY_HERE"/>
```
4. Replace `WEB3FORMS_KEY_HERE` with your access key
